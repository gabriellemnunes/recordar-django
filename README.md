# Recordar Django — AVA2
Dashboard de Gabrielle. Protótipo acadêmico local, sem autenticação de pacientes; use apenas dados fictícios. Referências: https://github.com/gabriellemnunes/backend-recordar e https://github.com/louisemartinss/recordar.frontend. Interface própria criada para a atividade, com paleta roxa. Os models compartilhados são uma proposta inicial; os demais integrantes devem implementar suas views e templates, substituindo as rotas provisórias em recordar/urls.py. Não duplique os models.

Windows: execute iniciar.bat. Ele instala Django, gera migrações, cria o banco, popula dados fictícios, executa testes e inicia o servidor. Mantenha o terminal aberto. Para capturar evidências, use Win+Shift+S na página http://127.0.0.1:8001/ após a execução. O banco é criado localmente. O CSS é incorporado ao HTML pelo template estilos.css, sem depender de uma requisição estática. Nenhum teste Django foi executado no ambiente de criação por falta da dependência e acesso à rede.
